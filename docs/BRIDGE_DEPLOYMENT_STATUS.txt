# Automatic helper deployment — public status

The master implementation is deployed. Boot startup and authenticated broker health were checked. The installed broker suite passed 18 tests. Native policy/queue/framing tests and extension automatic-access tests each passed nine tests locally.

Only the master initiates authenticated helper connections, restricted to its actual local subnet. Non-masters listen and never dial another peer. The extension contacts its own native host, with On/Off and Settings as the primary controls. Repeated browser pairing fields were removed.

Windows Server 2003 installation, DPAPI/task/firewall/native-host launch, reboot recovery and a live Gemini chat round-trip remain unverified. This is a development preview, not production acceptance.

The personalized installer contains private machine enrollment. Download information, storage identifiers, package hashes and operation receipts remain in the authorized private documentation. No such private distribution details belong in this public repository.
